Porti Negócios

Sistema full-stack de gestão operacional para a vertical de saúde da Portí Fintech. Centraliza dados de médicos, plantões, antecipações, contratos e produtos em uma plataforma unificada com IA analítica integrada.

Stack Tecnológico

Camadas de tecnologia do sistema — do banco de dados ao browser

Frontend
React 19 + Vite 6
React 19 com Concurrent Features. Vite 6 para bundling com HMR. Tailwind CSS 4 com design tokens Portí. shadcn/ui para componentes base. Wouter para roteamento client-side.
Backend
Express 4 + tRPC 11
Express 4 como servidor HTTP. tRPC 11 para contratos type-safe end-to-end. Superjson para serialização (Date, BigInt). tsx watch para hot reload em desenvolvimento.
Banco de Dados
TiDB Cloud + Drizzle
TiDB Cloud (MySQL 8 compatível) para tabelas de cache e API keys. Drizzle ORM para schema type-safe. Supabase PostgreSQL para tabelas de usuários OAuth. mysql2 pool para queries diretas.
Autenticação
Manus OAuth 2.0
OAuth 2.0 com PKCE via plataforma Manus. JWT assinado com jose. Cookie httpOnly + Secure + SameSite=Lax. protectedProcedure injeta ctx.user em todas as procedures.
IA & LLM
Claude 3.5 + RAG
Anthropic Claude 3.5 via invokeLLM(). Text-to-SQL com isSqlSafe() para proteção. RAG com chunking de documentos, embeddings TF-IDF e similaridade coseno. Fallback para queries SQL diretas.
Storage & Deploy
S3 + Manus Cloud
S3-compatible storage via Manus Forge API. storagePut/storageGet helpers pré-configurados. Deploy em Manus Cloud com Cloudflare CDN. Domínio: porti-dash-avdjpsei.manus.space.

// middleware.ts — validação da chave
async function requireApiKey(req, res, next) {
  const raw = req.headers.authorization
    ?.replace("Bearer ", "")
    || req.headers["x-api-key"];

  if (!raw) return res.status(401).json({...});

  // SHA-256 hash para lookup seguro
  const hash = crypto
    .createHash("sha256")
    .update(raw).digest("hex");

  // Busca no MySQL por keyHash
  const [rows] = await pool.execute(
    "SELECT * FROM api_keys WHERE keyHash=? AND active=1",
    [hash]
  );

  // Verifica scope + rate limit
  if (!hasScope(key, endpoint)) return 403;
  if (!checkRateLimit(key.id)) return 429;

  req.apiKey = key; next();
}

SQL Safety — isSqlSafe() para Text-to-SQL
// server/services/textToSql.ts
function isSqlSafe(sql: string): boolean {
  const BLOCKED = [
    "DROP", "DELETE", "UPDATE", "INSERT",
    "ALTER", "CREATE", "TRUNCATE", "EXEC",
    "GRANT", "REVOKE", "--", ";"
  ];
  const upper = sql.toUpperCase();
  return !BLOCKED.some(kw => upper.includes(kw));
}
// Apenas SELECT permitido · timeout 5000ms · queries parametrizadas
Session Cookie
httpOnly + Secure + SameSite=Lax. Assinado com JWT_SECRET via jose. Sem acesso JavaScript ao token.
CORS
Configurado no Express com whitelist de origens. Preflight OPTIONS tratado automaticamente. Credentials permitidas apenas para origens autorizadas.
Secrets Injection
Nenhuma variável sensível commitada no repositório. Todas injetadas pela plataforma Manus em runtime. Chaves nunca chegam ao bundle do browser.

function cosineSimilarity(a: number[], b: number[]) {
  const dot = a.reduce((s, v, i) => s + v * b[i], 0);
  return dot / (norm(a) * norm(b));
}
